# Supply Chain Correlation Analysis

This repository contains a comprehensive correlation analysis of supply chain data following Excel best practices.

## Files

- `correlation.csv` - Correlation matrix values
- `heatmap.png` - Heatmap visualization with conditional formatting
- `correlation_analysis.py` - Python script for analysis
- `q-excel-correlation-heatmap.xlsx` - Original dataset

## Analysis

The analysis examines correlations between five key supply chain variables:
- Supplier_Lead_Time
- Inventory_Levels  
- Order_Frequency
- Delivery_Performance
- Cost_Per_Unit
