# Quarterly Earnings — Reveal.js presentation

This repository contains a Reveal.js presentation for the Q3 2025 quarterly earnings.

**How to publish to GitHub Pages (docs folder method):**
1. Put `index.html` in the `docs/` folder
2. Commit & push to `main`
3. In GitHub settings -> Pages -> Source, set `main` branch and the `/docs` folder.

Once Pages is active, the site will be available at:
`https://<GITHUB_USERNAME>.github.io/<REPO>/`
