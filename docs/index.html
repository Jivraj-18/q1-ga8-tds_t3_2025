Sample calculation (Python)


# Simple NPV calculation (discount rate 8%)
def npv(cashflows, discount_rate):
    return sum(cf / ((1 + discount_rate) ** i) for i, cf in enumerate(cashflows, start=0))

cashflows = [-100000, 30000, 40000, 50000, 60000]
print("NPV:", npv(cashflows, 0.08))

Financial formulas

Return on Investment (ROI): $$\mathrm{ROI} = \frac{Gain - Cost}{Cost} \times 100\%$$
